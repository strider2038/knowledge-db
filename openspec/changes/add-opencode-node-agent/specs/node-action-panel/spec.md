## Purpose

Пояснение в модалке правки узла не называет поставщика агента.

## MODIFIED Requirements

### Requirement: Модальное окно инструкции для агента

UI SHALL открывать модальное окно при нажатии «Редактировать с агентом». Модалка MUST содержать многострочное поле для текстовой инструкции, краткое пояснение назначения и кнопки «Отмена» и «Запустить». Пояснение MUST описывать правку файла на сервере и MUST NOT называть конкретного поставщика агента. «Запустить» MUST быть disabled, пока инструкция пуста (после trim). При успешном старте модалка MUST закрываться и запускаться операция на сервере.

#### Scenario: Отмена без запуска

- **WHEN** пользователь нажимает «Отмена» или закрывает модалку
- **THEN** операция не запускается, состояние страницы не меняется

#### Scenario: Запуск с инструкцией

- **WHEN** пользователь вводит инструкцию и нажимает «Запустить»
- **THEN** UI вызывает API agent-edit с телом `instruction` и переходит к отображению прогресса

#### Scenario: Ошибка старта

- **WHEN** API возвращает ошибку при запуске
- **THEN** UI показывает диагностируемое сообщение; модалка MAY оставаться открытой для исправления инструкции

#### Scenario: Пояснение без имени поставщика

- **WHEN** пользователь открывает модалку «Редактировать с агентом»
- **THEN** текст пояснения не содержит «Cursor»
